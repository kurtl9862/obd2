# Car photos

Our own photos of the family's cars (October 2026), copied from Halberd's Vehicles view
(`kurtl9862/halberd`, branch `1.x`, `dashboard/web/public/cars/`). Background removed, plates blanked,
windows darkened. Trimmed to the car and converted to WebP here.

| File | Car |
| --- | --- |
| pathfinder-2010.webp | 2010 Nissan Pathfinder SE |
| civic-2020.webp | 2020 Honda Civic Sport sedan |
| sentra-2020.webp | 2020 Nissan Sentra SR |

To add a car: drop a cut-out photo here named after the profile id and add it to `web/src/lib/carPhotos.ts`.
